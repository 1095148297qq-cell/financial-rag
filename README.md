# 白酒财报问答知识库

第三周课程作业 · 方向 A。使用12家白酒上市公司的2024、2025年度报告，建立可追溯原文的问答知识库。项目在本机运行，无需公网部署。

用户直接用自然语言提问，系统以**向量 + BM25**检索年报，模型根据召回证据回答；每个引用均可展开查看原文、公司、章节、PDF页码和块ID，并跳转官方PDF。没有模型key也能只检索证据。

## 实现方法

1. **提取与切块**：逐页提取文字；根据表格线条还原行列，保留列名、单元格值和原始行。文字按约800字切块、重叠120字，表格同行不拆开。每块带公司、年度、章节、PDF物理页码及来源。
2. **混合检索**：本地`BAAI/bge-small-zh-v1.5`生成512维向量，结合jieba分词与BM25，通过RRF融合召回。向量计算不调用收费embedding API。
3. **自然语言问答**：默认全库和混合检索，无需手动选择数据库或索引。系统识别公司简称、年度和跨公司比较意图，补充相关表格证据；模型只根据召回材料回答，证据不足时应明确说明。
4. **出处与评测**：网页展示引用、原文块和官方PDF链接，可下载问答记录。逐题保存实际回答、召回块、对错判断及原因，不将自动数字检查当成人工评分。

## 本地运行

建议Python 3.11、Node.js 20+。首次下载模型、提取和建索引需要时间，后续使用本地缓存。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m financial_rag.download
.\.venv\Scripts\python.exe -m financial_rag.extract
.\.venv\Scripts\python.exe -m financial_rag.retrieval
powershell -ExecutionPolicy Bypass -File .\start-web.ps1
```

浏览器打开`http://127.0.0.1:3000`。关机后重新运行`start-web.ps1`；重启服务先运行`stop-web.ps1`。无需重新下载或建库。旧Streamlit入口可用`python -m streamlit run app.py`。

## 模型接入与成本

网页选择“模型 API · 使用自己的 key”，选择**OpenAI（GPT）、DeepSeek、通义千问（北京）或硅基流动（中国站）**，填对应key即可。接口地址和默认模型自动填写，可修改为账户有权限的模型ID。千问需使用北京地域key。

已有有效本机GPT授权的环境可选择“GPT · 本机已有授权”；凭据保存在仓库之外，仅供本机使用。其他使用者提供自己的key，无需作者提供凭据。

- 只检索证据不调用回答模型；API费用取决于用户所选服务商、模型及用量。
- key仅在页面内存及当前请求中使用，切换服务商会清空，不进入问答下载和评测文件。
- `.env`已加入`.gitignore`；环境变量示例见`.env.example`，不要提交真实key、密码或授权文件。
- 不自动重试或切换账户。API key模式最多输出3,500 tokens；证据超过60,000字符时停止生成。调用次数限制不等于货币预算。
- 第三方接入已做协议及密钥隔离测试，真实账户可用性仍需对应key、模型权限和余额。

## 10道评测题

1. 贵州茅台 2024、2025 年营业收入和归母净利润分别是多少？请按亿元列出并给出两份年报出处。
2. 五粮液 2025 年营业收入、归母净利润及其同比分别是多少？
3. 泸州老窖 2025 年经营活动现金流量净额和归母净利润是多少？前者约占后者多少百分比？ **【曾失败】** 漏召回归母净利润，比例无法计算。
4. 对照洋河股份 2024 和 2025 年年报，经营活动现金流量净额分别是多少？是否由正转负？
5. 古井贡酒 2025 年加权平均净资产收益率是多少？较 2024 年下降多少个百分点？
6. 山西汾酒 2025 年营业收入和归母净利润同比增幅分别是多少？两者相差多少个百分点？
7. 对照舍得酒业 2024 和 2025 年年报，两年经营活动现金流量净额是多少？2025 年仍为负吗？ **【曾失败】** 把现金净流出称为亏损，概念错误。
8. 水井坊 2025 年年报“可能面对的风险”列出哪两类风险？每类概括一项应对措施。
9. **【跨公司全景题】** 在本库 12 家白酒公司中，按 2025 年营业收入由高到低完整排序，列出各家金额（亿元）。覆盖不足时说明缺失公司。 **【曾失败】** 仅确认4家公司营收，排序未完成。
10. **【跨公司全景题】** 逐一列出本库 12 家公司的 2025 年营业收入同比增幅；共有几家增长，分别是谁？使用 2025 年年报中披露的 2024 年可比数据，列明证据覆盖。

第9、10题均要求覆盖本库全部12家公司。“曾失败”对应保留的真实失败记录，同题另有成功回答，不代表每次都失败。逐题原答、召回块、人工复核及历史失败材料只保存在本地交付材料中。

## 问答结论与限制

年度指标查询、跨年变化和跨公司排序表现较好，因为指标明确、原文相对集中，便于定位并引用。失败主要来自漏召回、报表口径混淆与计算：既有缺少分母而无法算比例，也有金额已召回却算错占比的情况。

同一批财报适合建库，因为事实会更新，答案需要可追溯出处。改进重点是拆分子问题、按口径定位、补全表格和覆盖检查，并用程序核算比例、换算与排序。少量固定题答对不能代表总体准确率；项目未做微调，不据此比较微调效果。

**表格还原仍有局限**：5,912个表格块表头未确认，不等于全部数值错误，但不能宣称所有表格完全准确。无框线、跨页、复杂或扫描表格可能遗漏；章节识别与长文本向量输入也有边界，关键金额须回到原文核验。

## 检查与复现

仓库提供下载、提取、建库和检查脚本。测试额外依赖安装后，可运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe -m financial_rag.audit_assignment --online
.\.venv\Scripts\python.exe -m financial_rag.check_public_files
```

`audit_assignment --online`核对上市公司披露、重新下载24份官方PDF进行SHA比对，并检查切块、索引及作者本地已复核的10题记录。不调用模型、不改写原答或评分。省略`--online`只做本地检查。新克隆者没有作者的私有评测记录，需先自行出题、生成答案并复核，不能直接使用作者的评分；评测入口为`prepare_evaluation`和`evaluate`，模型生成会消耗运行者的API余额或账户额度。

本机已完成官方文件比对、切块结构、关键金额/续表回归、37项自动测试、网页检索/引用/下载与10题记录完整性检查。详细报告保存在`交付材料/assignment_audit/`。这不等于全库逐单元格审计，也不代表已从空白系统完成全部依赖安装和重建。

`submission_pdf`仅依据作者本地已复核记录及核查结果排版一页结论，不生成或评分答案。财报、索引、缓存、评测记录、PDF及截图均被Git忽略。
